For a production system, sync must use authenticated APIs, version numbers, duplicate protection and conflict handling.

Production sync requirements

  • Android local database and web IndexedDB
  • Authenticated server API and facility-level permissions
  • Pending-change queue with retry and acknowledgements
  • Conflict resolution; never silently overwrite approved reports
  • Encryption, audit logs and secure backups
  • Visible last successful sync timestamp
